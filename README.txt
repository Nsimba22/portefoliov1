# Portefólio profissional — Nsimba Ângelo João Nioca

## Estrutura
- index.html — estrutura e conteúdo
- style.css — design responsivo, animações e efeitos
- script.js — menu mobile, scroll reveal, barras de competências, contadores, partículas e efeitos
- assets/perfil.jpg — foto usada no portefólio
- assets/cv.png — CV fornecido

## Como executar
1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Para publicar, envie todos os ficheiros mantendo a estrutura de pastas.

## Personalização
No `index.html` pode alterar links de LinkedIn, telefone, email e adicionar projectos reais.
